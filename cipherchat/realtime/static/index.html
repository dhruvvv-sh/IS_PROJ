[ PROTOCOL SPECIFICATION & SECURITY ARCHITECTURE ]

01 / Cryptographic Primitive Stack: X25519 ECDH key agreement establishes a 32-byte shared secret. HKDF-SHA-256 with domain-separated info labels derives the 256-bit AES-GCM session key. Messages are encrypted under AES-256-GCM with fresh 96-bit random nonces and canonical JSON Associated Authenticated Data (AAD). Envelopes are signed with Ed25519 for non-repudiation.

02 / Threat & Adversary Model: Mallory has network interception capability (Dolev-Yao model). Mallory can eavesdrop on ciphertext, inject modified envelopes, replay valid envelopes, and attempt public key substitution. Plaintext confidentiality and integrity are preserved under active attacks.

03 / Incident Handling & Recovery: Security violations generate tamper-evident SHA-256 hash-chained audit records. Rejected attacks transition the session to QUARANTINED, requiring cryptographic verification and rekeying. Key substitution transitions to BLOCKED.
